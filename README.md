# lucky-data — หลังบ้านของแอป สถิติสลาก

แอปโหลดไฟล์ในโฟลเดอร์ `data/` ทุกครั้งที่เปิด (ต้องเป็น repository แบบ Public)

| ไฟล์ | ใช้ทำอะไร | ใครแก้ |
|---|---|---|
| `data/draws.json` | ผลสลากกินแบ่งรัฐบาล | ระบบอัปเดตเองหลัง 16:45 น. ของทุกวัน |
| `data/daily.json` | ผลชุดรายวัน | ระบบอัปเดตเองทุกคืน จันทร์–ศุกร์ 21:15 น. |
| `data/daily_manual.json` | กรอกผลชุดรายวันเอง ถ้าระบบดึงไม่ได้ เช่น `[{"d": "2026-11-25", "s": "123456"}]` | คุณ |
| `data/config.json` | ค่าตั้งค่า (ด้านล่าง) | คุณ |

## config.json
- `thai.drawDates` — วันออกรางวัลงวดถัดไป ใส่ล่วงหน้าไว้ ถ้ามีงวดเลื่อน แก้วันที่ตรงนี้
- `thai.switchTime` — เวลาที่แอปเปลี่ยนไปงวดถัดไปในวันออกรางวัล (ค่าเริ่มต้น 16:00)
- `daily.switchTime` — เวลาเปลี่ยนวันของชุดรายวัน (20:30)
- `daily.holidays` — วันที่งดออกรางวัลชุดรายวัน เช่น `["2027-01-01"]`
- `announcement` — ข้อความประกาศบนหน้าแรกของแอป ปล่อยว่าง `""` เพื่อซ่อน

## รันระบบอัปเดตเอง
แท็บ **Actions** → **update-results** → **Run workflow**
